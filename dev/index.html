GroundSourceHeatPumpDesign.jl

Heat pump modelling for ground-source heat pump (GSHP) systems, part of the GHE.jl ecosystem.

This package sits at the same level as GroundHeatExchangerSizing.jl and ThermalResponseTest.jl, and like them depends on GroundHeatExchanger.jl for the ground-side physics. Its own heat pump/load layer has no ground-physics dependency and can be used on its own.

Early / in-development package

This package is at an early stage: it currently provides heat pump performance interpolation, building-to-ground load conversion and a minimal, non-iterative GSHP simulation workflow. Expect the public API to change without notice until the package reaches a tagged release.

What it does today

  • Heat pump performance interpolation (heat_pump_performance) — capacity (CAP) and coefficient of performance (COP) from manufacturer performance data, via 1D linear interpolation on the source entering fluid temperature (EFT) or 2D bilinear interpolation on both source and load EFTs. Values are clamped outside the provided grid.
  • Building-to-ground load conversion (Q_COP, ground_load_from_heat_pump, ground_load_capped) — converts a building heating/cooling load into the corresponding ground load using the heat pump's COP, respecting the sign convention that a building heating load extracts heat from the ground loop and a building cooling load rejects heat to it.
  • gshp_simulation — a full, single-pass GSHP simulation combining the above with GroundHeatExchanger.jl's g-function and effective borehole resistance, plus n_active_heat_pumps, unmet_hours, annual_drift and thermal_energy for reporting. Implemented as multiple methods of increasing complexity — see script/script_gshp_1_fixedCOP.jl and script/script_gshp_2_variableCOP.jl, and the Conventions section of the README for the sign convention and nomenclature used throughout.
